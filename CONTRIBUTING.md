# Contributing

Olladex welcomes focused bug fixes, compatibility reports, tests, and accessible UI improvements.

1. Fork the repository and create a short-lived branch.
2. Run `swift test` and `swift build` before opening a pull request.
3. Describe which Codex, Ollama, and macOS versions you verified.

Never include a user's `~/.codex/config.toml`, authentication files, prompts, or model output in fixtures or bug reports.
